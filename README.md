# Yale Astro 330 Labs

This repository contains my work on the publicly available materials for [Yale Astro 330](https://astro-330.github.io/intro.html), a course on astronomical data analysis and Python.

I'm working through the labs to get hands-on experience with the tools and methods used in observational astronomy. The exercises cover several aspects of astronomical data analysis:

## Topics

- **Astronomical Imaging:** Reading and displaying FITS files, working with WCS, image processing, and aperture photometry.
- **Photometry:** Background estimation, source detection, centroiding, and basic PSF measurements.
- **Model Fitting and MCMC:** Chi-square fitting, likelihoods and posteriors, Metropolis–Hastings sampling, and `emcee`.
- **Stellar Spectroscopy:** Working with observed and synthetic spectra, matching spectral resolution, and estimating radial velocities.
- **Catalog Analysis:** Working with astronomical catalogs using Pandas, including filtering, combining, and visualizing data.

## Tools

Python · NumPy · SciPy · Pandas · Astropy · Matplotlib · emcee · Jupyter Notebook

## About This Repository

This is a collection of course-based exercises and my own implementations along the way. It reflects my progress in learning how to work with astronomical data, from reading and processing observations to fitting models and interpreting results.

I will continue updating the notebooks and code as I work through the labs.
